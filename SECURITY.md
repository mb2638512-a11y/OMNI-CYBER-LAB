# Security Policy

Use OMNI CYBER LAB only on devices, applications, networks and backend environments that you own or are explicitly authorized to assess.

Report vulnerabilities privately to the repository owner. Do not include real credentials, personal data or third-party secrets in issue reports.

The current build performs metadata inspection and limited Shizuku-authorized read-only diagnostics. It is not a full penetration-testing suite and does not guarantee detection of all vulnerabilities.
